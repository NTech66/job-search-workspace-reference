# Glossary

- **Application answer template:** reviewed reusable wording or structure for common application questions. It is content, not executable code or proof of user facts.
- **Capability:** one explicit extension action, such as search, refresh, submit, or provide templates.
- **Extension:** a versioned in-app module for a source or feature; not a browser add-on.
- **Owner review:** manual safety and compatibility approval before publication.
- **Local role:** a role in a region selected by the user.
- **Remote global:** a remote role in any region returned by an enabled extension.
- **Verified profile fact:** user-supplied or confirmed information with origin/time; AI wording is not a fact.
- **Workplace mode:** remote, on-site, or hybrid. Separate from employment type.
- **Employment type:** full-time, part-time, contract, internship, temporary, or source-provided category.
- **Seniority:** internship, entry-level, mid-level, senior/advanced, or source-provided category.
- **Needs user input:** application paused because a required answer is missing, unclear, or unsupported.
- **Manual link:** a listing is discoverable, but no approved automatic submission capability exists.
