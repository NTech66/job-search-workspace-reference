# Job Search Workspace

Product reference and implementation plan for a bilingual Arabic/English job-search application with unified listings, editable profiles and private files, reviewed in-app extensions, reusable answer templates, and carefully gated AI-assisted applications.

## Status

This repository contains planning and product documentation only. It does not contain a built or deployed website, working integrations, or live job listings.

Start with [00 - Start Here](00%20-%20Start%20Here.md). The notes are organized as linked Obsidian Markdown documents. The source compatibility matrix intentionally remains unpopulated until each platform's official policies and permitted integration options have been checked.

## Scope

The initial launch is Egypt-focused, with Arabic and English interfaces. Users select their own region for local roles; remote search covers regions supported by enabled source extensions. Automatic applications must pause when a required answer is missing or unclear.
